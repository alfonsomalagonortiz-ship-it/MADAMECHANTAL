# Espacio de trabajo · Madame Chantal

Empresa de perfumería y venta directa.

Base para encargar trabajo a Codex con instrucciones persistentes, contexto verificable y seguimiento.

## Estado
Configuración inicial. Antes de incorporar documentación interna o datos de clientes, verificar que el repositorio sea privado.
Todavía no se ha incorporado la skill de marketing ni su evidencia. No se ha verificado un entorno de Codex conectado a este repositorio.
No hay conexión automática a Drive, WhatsApp ni historial de ChatGPT.

## Cómo pedir trabajo
Abre este repositorio en Codex y escribe el resultado que necesitas en lenguaje normal. Ejemplo:

> Lee AGENTS.md. Revisa la información disponible de Madame Chantal y prepara una propuesta de contenido para Facebook e Instagram. Usa únicamente datos vigentes con fuente; registra los faltantes y entrega una propuesta revisable sin publicar.

## Organización
- AGENTS.md: instrucciones comunes que debe leer el agente.
- clientes/PLANTILLA.md: ficha por marca o cliente comercial.
- encargos/PLANTILLA.md: objetivo, entregables, revisión y continuidad.
- .agents/skills/: ubicación prevista para procesos reutilizables, una vez verificada la privacidad.

Las fichas de marca son diferentes de un CRM de compradores. No registrar conversaciones, teléfonos, domicilios, pagos o credenciales en este repositorio público.
